# Gestion d'auto-école

Projet de fin de licence en Systèmes Informatiques.

## Description
Application web full stack de gestion intégrée destinée aux auto-écoles. 
Elle centralise la gestion de l'établissement et offre à chaque type d'utilisateur 
un espace personnel de suivi.

## Espaces utilisateurs
- **Espace candidat** : suivi de la progression, consultation du planning des séances, historique et paiements..
- **Espace moniteur** : gestion de son planning, suivi des candidats qui lui sont attribués, validation des séances..
- **Espace administrateur** : gestion des candidats, moniteurs, véhicules, séances et paiements....

## Technologies utilisées
- Front-end : HTML, CSS, JavaScript
- Back-end : PHP
- Base de données : MySQL
